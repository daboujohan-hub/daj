Politique de communication DAJ

AbouDev Labs · DEV.D.A.J. · San Pedro, Côte d'Ivoire

1. Pourquoi cette page existe

DAJ est le canal officiel entre le développeur et les vendeuses dont il gère la boutique. Il a été créé pour que les informations importantes circulent à un seul endroit, sur des services que le développeur contrôle lui-même, et non sur des applications tierces.

2. Ce qui doit passer par DAJ

  • Les demandes de modification ou de correction de la boutique.
  • Les photos, les prix et les informations de produits.
  • Les accès (mot de passe de l'espace vendeuse, code de connexion).
  • Les problèmes, pannes ou retards, et les décisions prises sur la boutique.

Tout ce qui est dit ailleurs (WhatsApp, appel, réseaux sociaux) et qui change la boutique doit être répété dans DAJ pour compter.

3. Ce qui ne doit jamais être envoyé, même dans DAJ

  • Numéro de carte bancaire, code secret de Mobile Money, code de confirmation reçu par SMS.
  • Pièce d'identité.

Le développeur ne te demandera jamais ces informations.

4. Où sont les données

Les messages et les photos sont stockés sur la base de données du développeur, accessible par lui seul. Une vendeuse ne voit que sa propre conversation. Les codes de connexion sont enregistrés sous forme chiffrée : le développeur lui-même ne peut pas les relire, il peut seulement en créer un nouveau.

Pour fonctionner, le développeur utilise deux fournisseurs techniques : Google (base de données Firestore) et Render (hébergement). DAJ n'utilise ni publicité, ni outil de statistiques, ni autre service de messagerie.

5. Tes droits

  • Demander une copie de ta conversation.
  • Demander la suppression de ton compte et de tes messages.
  • Demander un nouveau code si tu penses que l'ancien a été vu par quelqu'un.

6. Ce que DAJ ne garantit pas

Les messages ne sont pas chiffrés de bout en bout : ils sont protégés pendant le transport (HTTPS) et à l'accès, mais le développeur peut les lire. Les photos et les messages sont conservés tant que le compte existe.

7. Notifications et messages automatiques

Si tu actives les notifications, ton téléphone reçoit un signal par le service de ton navigateur (Google, Apple ou Mozilla). Le contenu est chiffré : ce service sait qu'une notification existe, il ne peut pas la lire. Tu peux les couper à tout moment dans DAJ.

Quand le développeur est absent, DAJ peut t'envoyer une réponse automatique, marquée « Message automatique ». Ce n'est pas une lecture de ton message.
